# Contributions

This repository is a **read-only publication**: it publishes datasets
derived by the [Nabu](https://github.com/arvicco/nabu) pipeline from
its own library, versioned and DOI-minted as a unit. Every table here
is a build artifact — regenerated whole by the pipeline, never edited
in place — so inbound data contributions (new rows, corrected values,
added datasets) cannot be merged: the next build would overwrite
them, and the DOI'd releases must stay reproducible from the pipeline
alone.

**Defect reports are welcome.** If a value looks wrong, a file fails
to parse, or metadata misleads, please open an issue — the fix lands
upstream in the pipeline or its sources and arrives here with the
next release. Issues that point at the exact file, row and expected
value are the fastest to act on.

If you build something on these datasets, the licenses (see each
dataset's metadata and the repository LICENSE) say what they ask of
you — mostly attribution. We're glad to hear about downstream uses in
an issue, and the citation file (`CITATION.cff`) gives the reference
form.
